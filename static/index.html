如果不同意 AI 的维度划分，怎么改
改名：只改 name_zh，让名字更贴近业务语言。
删除：删除不该成为一级维度的整段对象。
合并：保留更准确的那个维度，把另一个维度的 source_atomic_tags 合进去，并同步改定义和边界。
拆分：复制一段维度对象，分别改名称、定义、P/N/M/0 规则和来源原子标签。
改边界：重点改 p_rule_zh / n_rule_zh / m_rule_zh / zero_rule_zh / boundary_zh，避免后续打标跑偏。
Context：只放人群、场景、用途、购买路径、使用阻碍等背景，不放产品性能好坏。
高级编辑：直接修改维度规则 JSON
